# URL Shortener for PrestaShop

**Create short, custom URLs directly on your own domain.**

This PrestaShop module allows you to create shortened links (e.g., `https://yourdomain.com/go/shoes`) that permanently redirect (301) to any target URL you specify (e.g., filtered search results, specific product pages, or external links).

## Features

- **Custom Short Codes**: define simple paths like `/go/promo` or `/go/summer-sale`.
- **Permanent Redirects (301)**: SEO-friendly redirects that pass link equity.
- **Click Tracking**: basic counter for how many times a short link has been used.
- **Internal Management**: easy-to-use interface within the PrestaShop Back Office.

## Installation

1.  Download or clone this repository into your `modules/` directory as `urlshortener`.
    -   Folder name must be exactly `urlshortener`.
2.  Log in to your PrestaShop Back Office.
3.  Go to **Modules > Module Manager**.
4.  Search for "URL Shortener".
5.  Click **Install**.

## Usage

1.  Go to the module configuration page.
2.  **Add New Shortcut**:
    -   **Code**: The short path you want (e.g., `myshoes`). This will be available at `https://yourdomain.com/go/myshoes`.
    -   **Target URL**: The full destination URL (absolute path, e.g., `https://yourdomain.com/search?controller=search&s=shoes`).
3.  Click **Save**.
4.  The new short link is now active immediately.
